# Slot 12 · Sat 30 Jan, evening — CLOSING WEEKEND

*Camp Loon Point shuts for good on Monday. Eight of you stayed for one more night.*

**System:** Call of Cthulhu 7e — **modern rules, set September 1986** ·
**4–6 players** · 4-hour slot (3h30 budget, 3h20 planned — 15·60·70·40·15, the
tightest on the slate, to give Act Three forty minutes) · **a slasher**, played knowingly · high
character turnover with second characters built in · the climax is a name, not a
weapon.

**Status:** **v1.1 — desk pass 1 applied; desk pass 2 run.** Next: apply pass 2's five fixes &mdash; **only one second character can say the name, and Act Three is not written for a table of them**, which is the critical one &mdash; then pass 3 from the player chair with a table that walks forward immediately, and one that wears the mask.

**Remaining prep:** the camp map — the centrepiece
prop · handouts (1931 and 1954 newspaper clippings, the camp's incident log, a
Polaroid) · art · pass-2 fixes, then desk pass 3 · print pack.

**Slot note:** moved here from Thursday afternoon on 2026-10-25. **Saturday
night is where this game always wanted to be** — a slasher at 7.30 on the
convention's last full evening, with a table that has been drinking together
for three days, is a considerably easier sell than the same game at two in the
afternoon. The first ninety minutes are still written to be funny and must
still be played that way; that was never about the slot.
