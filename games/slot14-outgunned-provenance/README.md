# Slot 14 · Sun 31 Jan, afternoon — PROVENANCE

*They are not stealing it. They have the paperwork, the export licence and a clear moral case, and they are putting it back.*

**System:** Outgunned (Two Little Mice) · **4–6 players** · 4-hour slot (3h30
play) · 1938, pulp adventure with the supernatural in it · the climax is a
document and a hole in a dry riverbed.

**Remaining prep:** scenario v1 · 5 pregens (Outgunned Roles and Tropes, each

**Slot note:** this is the **last game of the convention**, and it deliberately
changes the closer's character. The slot used to hold THE PERPETUAL ORDER — one
room, no violence, quiet existential dread. It now holds a pulp adventure with
a truck chase in it. Sending people home loud rather than hushed is a defensible
choice, but it is a choice.
